# Authorized lyric library

Put the church's approved lyric sheets here as `.txt` files (format: see `../../.claude/skills/worshipflow/SKILL.md`).
Only add lyrics the church is licensed to display (for example a CCLI SongSelect export under the
church's CCLI license) and set `authorized: true` only when that is true.

This folder is git-ignored except this README so copyrighted lyrics are never pushed to GitHub.
