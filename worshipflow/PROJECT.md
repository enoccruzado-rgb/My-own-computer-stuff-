# WorshipFlow AI

Goal: a volunteer says "build Sunday's songs" and gets native, editable ProPresenter 22 presentations
(groups, natural 1-2 line slides, the arrangement, the church theme), checked, approved and ready.
First customer: The Way Church, Milford MA (Apple Silicon Mac mini, 1920x1080 LED wall via NovaStar VX400).

Priorities: P0 native creation → P1 segmentation → P2 arrangements → P3 themes → P4 QA → P5 Claude Code
(MCP + skill) → P6 performance analysis → P7 secure remote → P8 commercial.

Milestone 1 (acceptance test) is done only when a real song file is imported, opened, saved, reopened
and verified **inside ProPresenter 22**. See TASKS.md for status.
