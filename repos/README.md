## Getting the files

```bash
git clone --recurse-submodules https://github.com/enoccruzado-rgb/My-own-computer-stuff-
# or, in an existing clone:
git submodule update --init --recursive
```

Update all to their latest versions: `git submodule update --remote`.

These are third-party code. Read each repo's README and license before installing anything from it.
